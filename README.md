# SALUD DATA 360

### Sistema Integrado de Gestión, Calidad, Seguridad y Analítica de Datos Sanitarios

## 1. Presentación del proyecto

SALUD DATA 360 es un proyecto académico orientado al diseño y planificación de un sistema integrado para la gestión, seguridad, calidad y análisis de datos sanitarios, tomando como referencia el desafío DataSalud Perú y el contexto de DIRESA La Libertad.

## 2. Contexto

El proyecto busca abordar las necesidades relacionadas con el manejo de información sanitaria, considerando aspectos como la organización de datos, automatización de procesos, seguridad de la información y análisis de datos para apoyar la toma de decisiones.

## 3. Objetivo general

Diseñar e implementar progresivamente una solución integrada que permita gestionar, proteger y analizar información sanitaria mediante herramientas de bases de datos y tecnologías de análisis de datos.

## 4. Alcance del proyecto

El trabajo contempla las siguientes áreas:

- Gestión de bases de datos relacionales.
- Automatización y auditoría de procesos.
- Seguridad y administración de información.
- Bases de datos NoSQL.
- Diseño de Data Warehouse y procesos ETL.
- Visualización de indicadores mediante herramientas BI.
- Procesamiento de datos con tecnologías Big Data.

## 5. Tecnologías previstas

- SQL Server
- MongoDB
- Power BI
- Apache Spark y PySpark
- GitHub

## 6. Estructura del repositorio

El repositorio está organizado en carpetas para documentar y desarrollar progresivamente cada componente del proyecto.

## 7. Estado del proyecto

Los componentes técnicos se incorporarán progresivamente conforme avance el curso.
